# Ragdoll Simulator 2
Ragdoll Simulator 2.0 is a Sequel to the Original Unity Version of the game. The Sequel was created in Unreal Engine 5.5.4.

Ragdoll Simulator 2.0 is a game where you just... ragdoll and play with the sandbox environment. Create creative chaos, play with friends using the multiplayer system, and **have fun!** Best part? The game is ***free***.

# Basics
In order to get started, you first want to start with the baby steps, right? Get started by exploring the environment. Want something different? Press **Escape** then you can pick out a different map.

# Multiplayer
Multiplayer works similar to LAN Minecraft. Click on Host in your pause menu if you are hosting.

# Modding
In order to start modding or making your own version, you will need if you are using this to create your own version of the game, you will need the following:
- Unreal Editor 5.5.4
- Decent PC (Sorry Potato Users)
- Some Blueprint Knowledge
As long as you understand these, you should be good to go.
For more information on modding, go the ***Wiki*** on the Github page.
