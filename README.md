# Ragdoll Simulator 2
Ragdoll Simulator 2.0 is a Sequel to the Original Unity Version of the game. It was created in Unreal Engine 5.5.4.

Ragdoll Simulator 2.0 is a game where you just... ragdoll and play with the sandbox environment. Create creative chaos, play with friends using the multiplayer system, and **have fun!**

# Modding
In order to start modding or making your own version, you will need if you are using this to create your own version of the game, you will need the following:
# - Unreal Editor 5.5.4
# - Decent PC (Sorry Potato Users)
# - Some Blueprint Knowledge
As long as you understand these, you should be good to go.
